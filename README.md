## 跨境专线不是普通 VPS，先认清三个底层概念

在选择专线之前，先把容易混淆的三类线路说清楚，否则后面的价格表会觉得每条都差不多。

**IEPL（International Ethernet Private Line）** 是点对点的物理专线，本质是把两个节点的端口直接连起来，不经过公网跳转发。Mkcloud 的广港 IEPL（广东-香港 IEPL专线）走的就是这条底层，端内参考延迟 1–2ms。

**IPLC（International Private Leased Circuit）** 与 IEPL 经常被混称，实际差别主要在协议封装和业务承载方式。Mkcloud 把它用在上海方向，沪港 IPLC、沪日 IPLC、沪美 IPLC 都属于这一类，端内参考延迟分别为 21ms、25–28ms、124–134ms。

**IX（Internet Exchange）上云互联专线** 不是直连产品，是从云厂机房出发、通过 BGP 通道接入 Mkcloud 内网，再从香港 BGP 出口出去。它必须搭配阿里云 / 腾讯云 / 百度云等云厂网络使用，普通的家宽连不上。端内参考延迟同样可以做到 1–2ms，但前置成本不能忽略。

记住这几条后，选线的方向就比"看名字"清晰很多。

## 选跨境专线前，先回答这五个问题

不管服务商是哪一家，专线选型的底层逻辑是一样的。Mkcloud 知识库里也把这套逻辑整理成了 60 秒选择表。

1. **目标出口在哪里**——香港、日本还是美国，先确认业务到底要连到哪个地区。
2. **从什么网络接入**——本地宽带走直连，还是已有云厂机器走 IX。
3. **本地省份和运营商**——直连款一次绑定一个省份，IP 变化时要重新切换；广东、上海、福建各自有不同的入口选择。
4. **短时峰值还是持续带宽**——决定选共享带宽的流量计费，还是独享带宽的不限流量。
5. **是否需要高防、SLA、路由定制**——这类需求不属于标准套餐，必须先提交工单确认费用和范围。

如果你的业务需要公网入站（公开站点、支付回调、邮箱接收、外部游戏服务端），这类出口型专线是不适合的——它们主动向外连接，不接受外部连入。这一点比线路名称本身更重要。

## 共享流量计费 vs 独享带宽，怎么选不浪费

这两类套餐最大的区别不是"哪个更高级"，而是看你的业务时段。

**共享流量计费**适合：间歇访问、短时上传、跨境电商后台登录、广告投放管理、海外平台运营等场景。峰值带宽高（200M–1G），但只是峰值，不保证持续跑满；流量按月设定额度，超量后自动暂停或限速。

**独享带宽**适合：长时间保持稳定传输速率，例如视频拉流、素材同步、定时数据备份、爬虫与采集任务。这类不设月流量额度，按配置带宽稳定输出。广港 IEPL 的独享档从 100M（¥1600/月）一路到 5G（¥35000/月），大带宽独享专线还包含 300Gbps DDoS 高防。

一个常见误区是把"峰值 500M"和"独享 500M"放一起比。共享套餐的 500M 是峰值，独享的 500M 是持续速率，预算和实际表现都不是一个口径。

## 常见疑问

**延迟最低的线路就是最合适的吗？**
不一定。1–2ms 是端内参考延迟，不是用户到目标网站的全程。还要确认入口能否连入、目标出口是否匹配、流量或带宽是否够用、服务器配置吃不吃得下你的业务。

**可以先买共享再升级独享吗？**
可以，提交工单申请升降级。降级时差价不退，IP 是否保留以工单处理为准。

**所有线路都能从任意省份接入吗？**
直连款每个套餐绑定一个省份，可自行切换。IX 产品不限省份但必须从云厂网络接入，普通家宽无法使用。

**沪美 124–134ms 比沪港慢那么多，值吗？**
跨太平洋物理距离决定了基础延迟，再低也很难突破 100ms 级。如果你的业务是美国方向后台管理、广告投放或素材传输，先用 1TB / ¥428/月试水再决定升档。

**上海 CN2 算不算海外专线？**
不算。它的入口和出口都在上海，是国内优化产品；要看海外出口请用沪港 / 沪日 / 沪美。
